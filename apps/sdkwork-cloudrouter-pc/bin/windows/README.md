# Windows Host Helpers

Reserved for Windows desktop packaging and launcher helpers once a `sdkwork-cloudrouter-pc-tauri`, `-pc-electron`, or `-pc-capacitor` host package ships (`DESKTOP_APP_ARCHITECTURE_SPEC.md`).

# macOS Host Helpers

Reserved for macOS desktop packaging and launcher helpers once a `sdkwork-cloudrouter-pc-tauri`, `-pc-electron`, or `-pc-capacitor` host package ships (`DESKTOP_APP_ARCHITECTURE_SPEC.md`).

Until then, use the repository root entrypoints (`pnpm dev`, `pnpm build`, `pnpm start`); this directory holds no runnable script.

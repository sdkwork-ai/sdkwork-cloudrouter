# sdkwork-space 全应用 money 显示统一（19 个仓库）

## 已盘点结论（3 路并行扫描）
- ~100 个仓库中 **19 个**有前端金额显示（其余 30+ 无金额 UI；inventory/invoice/catalog 无前端）
- 所有相关仓库 pnpm-workspace 均已链接 `../sdkwork-utils/packages/sdkwork-utils-typescript`（money 模块可引入；appstore 的 pc 包需补 `@sdkwork/utils` 依赖）
- 商业系仓库（account/order/payment/membership/promotion/mall）**全部收敛到同一链路**：feature `*-intl.tsx` → 各仓库 service 的 `formatSdkwork*CurrencyCny` → `@sdkwork/utils formatCurrency`（旧 currency 模块，fr/ru 分隔符有缺陷，money 模块修正）
- 其余为本地 helper（models/manager/agentstudio/im/notary/appstore）或裸 JSX `¥{price}`/`toFixed`（shop/community/course/knowledgebase/local-router/customerservice/games）

## 统一规则（与 clawrouter 完全一致）
- 价格/余额/充值/提现/订单金额 → `formatMoney` **symbol 模式**（locale 感知符号位置与分隔符）
- 成本/费用/点数账本 → **decimal 模式**（纯数字，视觉不变）
- 未知币种 → 回退原显示；i18n 翻译文案中嵌入的 `¥`/`$`（如 "立刻支付 ¥{{amount}}"）不动
- 旧 `formatCurrency` 保留（其他消费方仍可用），`formatSdkwork*CurrencyCny` 等包装函数改走 money 且**签名不变**

### Phase 3 — 测试断言同步 + 回归

- 每仓库：受影响测试 + typecheck 对比基线（**只保证 0 新增错误**，既有兄弟仓库生成 SDK 漂移类失败如实报告）+ 相关包 build（尽力）
- 全面扫描每仓库至零：`Intl.NumberFormat` currency 用法、`¥`/`$` JSX 硬编码、`{amount} {currencyCode}` 拼接、本地 formatCurrency/formatPrice 定义

## 并行执行方式
- 每个仓库组由 1 个 general-purpose subagent 执行（精确迁移模式 + 验收命令），主线程汇总 diff 与验证结果
- 仓库组划分：A=commerce 服务层 6 仓（account/order/payment/membership/promotion/mall）；B=models/manager/notary/agentstudio/im；C=裸 JSX 8 仓（shop/appstore/community/course/knowledgebase/local-router/customerservice/games）
- 完成后统一回归扫描 + 汇总报告

## 风险与说明
- 各仓库均存在不同程度的既有 typecheck/测试失败（兄弟仓库生成 SDK TS6133 漂移、在途改动），验收标准为"相对基线 0 新增"
- mall 跨仓导入 order/account service 的格式化自动继承，无需重复改造
- 视觉变化点：code 风格串（"CNY 599 / year"）→ symbol 风格（"¥599 / year"）；部分裸 `¥{price}` 获得千分位分组
- 移动端（order-mobile/shop-mobile/community-mobile/course-mobile）一并纳入

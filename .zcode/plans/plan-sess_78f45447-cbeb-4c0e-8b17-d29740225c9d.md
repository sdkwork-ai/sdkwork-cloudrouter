## 目标

将 admin「上游管理」页内通过 tab 切换的三大区块（上游供应商 / 上游账号 / 账号分组）拆分为左侧菜单中的三个独立菜单项，各自拥有独立路由与独立页面组件，便于独立开发维护。`/admin/upstream` 保留为兼容重定向（→ `/admin/upstream/suppliers`）。

## 改动内容

### 1. 菜单注册 `apps/sdkwork-clawrouter-pc/packages/sdkwork-clawrouter-pc-admin-shell/src/adminModuleRegistry.ts`
- lucide 图标新增 `Building2`、`UsersRound`、`Layers3`。
- `admin.menu.home.upstreamManagement` 分组由 1 项改为 3 项：
  - `/admin/upstream/suppliers` → `admin.menu.upstream.suppliers`（Building2，青）
  - `/admin/upstream/accounts` → `admin.menu.upstream.accounts`（UsersRound，紫）
  - `/admin/upstream/account-groups` → `admin.menu.upstream.accountGroups`（Layers3，琥珀）
- 高亮/模块归属逻辑无需改：`home` 模块 `pathPrefixes` 已含 `/admin/upstream`，`adminSidebarActive.ts` 按最长前缀匹配单个菜单项。

### 2. 菜单文案 `apps/sdkwork-clawrouter-pc/packages/sdkwork-clawrouter-pc-i18n/src/resources/admin/core-navigation.ts`
- 删除 `admin.menu.upstream`（上游路由 / Upstream Routing）。
- 新增三个 key（zh + en）：`admin.menu.upstream.suppliers`（上游供应商 / Upstream Suppliers）、`admin.menu.upstream.accounts`（上游账号 / Upstream Accounts）、`admin.menu.upstream.accountGroups`（账号分组 / Account Groups）。

### 3. 上游包改造 `apps/sdkwork-clawrouter-pc/packages/sdkwork-clawrouter-pc-admin-upstream/src/`
- 文件重命名（git mv）：`supplierTab.tsx` → `suppliersPage.tsx`、`accountTab.tsx` → `accountsPage.tsx`、`accountGroupTab.tsx` → `accountGroupsPage.tsx`。
- 组件重命名：`SupplierTab`/`AccountTab`/`AccountGroupTab` → `UpstreamSupplierAdmin`/`UpstreamAccountAdmin`/`UpstreamAccountGroupAdmin`（与 `DashboardAdmin`、`MonitorAdmin` 命名一致），每个页面 = 页面头部（标题+副标题）+ 原有内容（表格/弹窗/侧栏逻辑不动）。
- `components.tsx` 新增共享 `UpstreamPageShell`（沿用现有 header 样式，去掉 tab 栏）。
- `index.tsx`：删除 `UpstreamAdmin`、`views` 数组与 tab 栏逻辑；改为 re-export 三个页面组件 + `upstreamService`。
- 保留 `data-admin-upstream-toolbar/search/primary-action` 等测试依赖的属性标记。

### 4. 上游 i18n `src/i18n/zh-CN/ai/upstream/shared.ts` + en-US
- 删除 `admin.upstream.title`、`admin.upstream.subtitle`、`admin.upstream.views.label`、`admin.upstream.views.*`。
- 新增每页标题/副标题（zh + en）：`admin.upstream.suppliers.title/.subtitle`、`admin.upstream.accounts.title/.subtitle`、`admin.upstream.accountGroups.title/.subtitle`。

### 5. 路由 `apps/sdkwork-clawrouter-pc/src/admin/clawRouterAdminHostMount.tsx`
- 单个 `UpstreamAdmin` lazy 导入替换为三个（均来自 `@sdkwork/clawrouter-pc-admin-upstream`）。
- 路由贡献改为 4 条（权限均为 `clawrouter.admin.access`，SDK 族 `clawrouter-backend-sdk`）：
  - `upstream` → `<Navigate to="/admin/upstream/suppliers" replace />`（旧链接兼容）
  - `upstream/suppliers`、`upstream/accounts`、`upstream/account-groups` → 三个独立页面

### 6. 路由分类文档 `docs/schema-registry/frontend-route-classification.yaml`
- 保留 `route: /admin/upstream` 条目，`operation_routes` 扩展为四个路径。

## 目标

创建/编辑 API Key 改用 **GroupPicker 穿梭器**（多选），一个 Key 可绑定多个分组：后端打通 `iam_gateway_api_key_account_group`（binding_role='route'）写入（该表读端已完备、生产代码从未写入），契约+SDK 重新生成，前端表单/回显/行内切换全链路对齐。

## 1. 后端：API Key 多分组绑定

**请求/响应契约**（`services/.../api/app_api_keys.rs` + SDK 契约）：
- `AppApiKeyCreateRequest` / `AppApiKeyUpdateRequest` 新增 `account_groups: Option<Vec<String>>`（分组 code 数组，**全量替换**语义）；保留 `account_group`/`account_group_id` 兼容（未传 accountGroups 时回退单值解析）
- 解析逻辑：`accountGroups` 去重后逐个校验存在（找不到即 400）；**数组第一个 = 默认分组**（写 `iam_gateway_api_key.account_group_id`）
- 响应 `AppApiKeyItem` 新增 `accountGroups: string[]`（绑定并集 code，按 priority 序，含默认分组），`accountGroup/accountGroupName` 保留（默认分组语义）

**命令存储**（`api_key_command_store.rs`）：
- `CreateGatewayApiKeyCommand`/`UpdateGatewayApiKeyCommand` 加绑定列表；`create_gateway_api_key` 事务内 INSERT `iam_gateway_api_key_account_group`（binding_role='route'、priority 按序、status=1、effective 为空）
- `update_gateway_api_key` 全量替换：事务内 DELETE 旧绑定 + INSERT 新绑定
- key 删除（delete）时同步清理绑定表（现有 FK/删除路径核对）

**读端**：`snapshot.rs` 的 bindings 聚合（UNION 绑定表 + 默认分组）自动生效；`to_item_response_with_used_quota` 聚合 `accountGroups` 回显

## 2. 契约 + SDK 重新生成

- `frontend-field-contracts.yaml`：api key create/update 请求加 `accountGroups`（nullable string[]，maxLength 128/项）；响应加 `accountGroups: string[]`；更新 required 列表
- 生成链：`api_contract_manifest` → `clawrouter_openapi_generator` → app SDK 重新生成 → guardians → `api:materialize:write` + check

## 3. 前端改造

**GroupPicker 组件增强**（commons）：新增 `onOpen?: () => void` prop（打开 Dialog 时触发，供懒加载分组）

**api-keys 包**：
- `accountGroups.ts`：新增 `toGroupPickerOptions(groups): GroupPickerOption[]`（**带 vendorCode/modalities**，供穿梭器 vendor/模态筛选）
- `apiKeyForm.ts`：`ApiKeyFormValues.accountGroup: string` → `accountGroups: string[]`；空数组回退 `[DEFAULT_ACCOUNT_GROUP]`；批量创建复制
- `apiKeyService.ts`：`ApiKey` 加 `accountGroups: string[]`（normalize 读响应）；`CreateApiKeyInput.accountGroups: string[]`；`toCreateApiKeyRequest`/`toUpdateApiKeyRequest` 映射 SDK 新字段 `accountGroups`
- `CreateKeyDrawer.tsx`：GroupSelector → **GroupPicker**（selectionMode="multiple"、onOpen=onRequestGroups 懒加载、vendor/模态筛选可用、labels 走 i18n 含模态标签）；state 改 `accountGroups: string[]`（创建初始 `[defaultGroup]`，编辑回显 `initialData.accountGroups`，老数据回退 `[accountGroup]`）；canSubmit 要求非空
- `ApiKeysView.tsx`：创建/编辑提交传数组；**行内分组切换**改为 GroupPicker（紧凑 trigger 样式，显示默认分组名 + 绑定数徽章，点击打开穿梭器管理多分组），`handleGroupChange` → 全量 `updateKey({ accountGroups })`；删除行内 GroupSelector/hoverCard 逻辑

**i18n**（en/zh）：GroupPicker 所需键（选择分组/全部厂商/全部模态/可用/已选/添加全部/移除全部/清空/确认/取消/未选择分组等）
